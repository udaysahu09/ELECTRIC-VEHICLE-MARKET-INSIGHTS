# Electric Vehicle Market Performance & Insights

An interactive Tableau dashboard exploring electric vehicle manufacturers, driving range, battery capacity, and vehicle body types.

## Dashboard Preview

![EV Market Insights Dashboard](screenshots/dashboard.png)

## Key Metrics
- **Total EV models:** 478
- **Average driving range:** 393 km
- **Average battery capacity:** 74 kWh

## Dashboard Views
1. **Top 10 Manufacturers** — compares manufacturers by distinct model count.
2. **Average Range by Brand** — compares average driving range across brands.
3. **EVs by Body Type** — shows the distribution of vehicle models by body type.

## Files
- `EV_Market_Insights_Improved.twbx` — packaged Tableau workbook.
- `electric_vehicles_spec_2025.csv` — source dataset.
- `screenshots/dashboard.png` — dashboard preview.

## Tools
- Tableau
- CSV dataset analysis and visualization

## How to Open
Download the `.twbx` file and open it with Tableau Desktop.

## Notes
KPI values are rounded for display. Dashboard rendering and data-source compatibility should be checked in Tableau Desktop before treating this as a final published version.
